# 💕 Swear Jar

A cute and playful couple web app where both partners add a coin to a shared "swear jar" whenever they fight 😄

Built with ❤️ using Firebase and vanilla JavaScript, this app syncs in real-time across devices and adds a fun twist to resolving conflicts.

---

## ✨ Features

- 🪙 Add coins when you or your partner "mess up"
- 🔄 Real-time sync using Firebase (works across devices)
- 🔐 Google & Guest login support
- 📜 Fight history tracking
- ⏳ Peace streak counter (days without fights)
- 🎯 "Who fights more" analytics
- 🔊 Cute sound effects & voice lines
- 🎞️ Coin drop animation into jar
- 📱 Installable as a PWA (works like an app)

---

## 💡 How It Works

1. Login using Google or Guest mode
2. Enter the same Couple ID on both devices
3. Start tracking fights 😅
4. Data syncs instantly using Firebase Firestore

---

## 🛠️ Tech Stack

- HTML, CSS, JavaScript (no frameworks)
- Firebase Authentication
- Firebase Firestore (real-time database)
- Progressive Web App (PWA)
